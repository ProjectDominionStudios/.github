# Project Dominion Studios organization defaults

Status: **Published Knowledge**

Knowledge Object ID: `PDS-KO-PUB-GITHUB-REPO-0001`

This public repository provides the Project Dominion Studios organization
profile and default community-health documents used by GitHub repositories that
do not supply a more specific local version.

Public placement is intentional. Repository-specific governance takes
precedence when it is stricter or more specific. These defaults do not grant
access, approval, deployment authority, publication authority, or permission to
disclose nonpublic information.

See [Publication provenance](PUBLICATION-PROVENANCE.md) for the approved source
revision, sanitization boundary, integrity inventory, and rollback evidence.

## Approved publication closeout

These defaults describe the effect of an authorized human's publication approval; they do not supply that approval themselves. The [published contribution rule](CONTRIBUTING.md#publication-approval-and-github-closeout) makes verified GitHub closeout part of the same approved topic. Contribution and PR guidance below implement that rule while preserving required checks, protections and explicit scope exclusions.
