# Project Dominion Studios

**Games and technology, built with purpose.**

Project Dominion Studios is a technology and innovation studio focused on
practical software, responsible AI and automation, developer tools, cloud and
infrastructure solutions, research, and interactive experiences.

## Mission

Build useful, maintainable technology through curiosity, disciplined
engineering, continuous learning, responsible AI collaboration, and clear
documentation.

## What we build

- Business and productivity applications that simplify real work.
- Responsible AI-assisted workflows and automation.
- Developer tools, validators, diagnostics, and generators.
- Secure, maintainable cloud and infrastructure solutions.
- Research projects and documented proofs of concept.
- Games, simulations, mods, and narrative experiences.

## Flagship interactive project

**Galactic Dominion** is a turn-oriented multiplayer strategy game centered on
exploration, empire-building, diplomacy, fleet command, and a living shared
galaxy. **Project Dominion** is its internal development codename.

## How we work

- One issue maps to one short-lived branch and one pull request.
- Changes remain reviewable, testable, documented, and recoverable.
- Humans remain accountable for decisions and external effects.
- AI-assisted work is reviewed for accuracy, security, privacy, licensing, and
  accessibility.
- Canonical knowledge is referenced instead of silently duplicated.
- Valuable new ideas are captured without disrupting the active objective.

## Studio principles

- Build with purpose.
- Finish before expanding.
- Prefer evidence over assumptions.
- Keep systems simple, secure, and maintainable.
- Protect privacy, security, contributor health, and trust.
- Leave every project better than you found it.
- Technology should serve people.

We do not just build software. We build systems, knowledge, tools, and
experiences—and we leave things better than we found them.
